# 🎬 Motion App

> Auto Caption + Motion Graphics Video Generator — built with React Native + Expo

[![Build APK](https://github.com/YOUR_USERNAME/motion-app/actions/workflows/build-apk.yml/badge.svg)](https://github.com/YOUR_USERNAME/motion-app/actions/workflows/build-apk.yml)

## ✨ Features

- 🎙️ **SRT File Upload** → Auto JSON convert (no AI needed)
- 🎨 **20 Motion Templates** — 5 unique style categories
- 🖼️ **Logo Overlay** — 9 position options with opacity control
- 🔊 **Sound Effects** — 6 built-in SFX categories
- 🖋️ **Bengali + English Fonts** — 10 stylish font options
- 📐 **Dual Export** — 9:16 Reel + 16:9 YouTube
- 💯 **100% Free** — No API key needed
